# Aether

A minimal static site generator written in Go.

See the **[documentation](https://isa0-gh.github.io/aether/)** for setup, usage, and deployment.

## Quick start

```sh
git clone https://github.com/isa0-gh/aether my-site
cd my-site
# edit config.json, add posts to content/
go run ./cmd/aether/main.go
```

Output is written to `public/`.
